INSTRUCCIONES PARA ACTIVAR EL PAQUETE "RELOAD"
============================================

1. Ve a la página de pricing.html.
2. En la sección de paquetes (Starter, Premium, Deluxe), verás un pequeño punto casi invisible a la derecha del botón "Deluxe".
3. Haz clic en ese punto para activar el Modo Reload.
4. Verás una animación de "quiebre" de pantalla con un flash rojo y la interfaz cambiará a un tono rojo/oscuro (Modo Especial).
5. En este modo, los límites de descuento se eliminan (puedes poner 0% a 100%) y el paquete se guardará con el nombre "Reload".

SQL PARA ACTUALIZAR SUPABASE
============================

Ejecuta el siguiente SQL en el editor de Supabase para registrar el preset oficialmente (necesario para la administración):

INSERT INTO pricing_presets (tier, service_ids)
VALUES ('reload', ARRAY['online_orders', 'local_listing', 'social_media', 'smm', 'physical_marketing'])
ON CONFLICT (tier) DO UPDATE SET service_ids = EXCLUDED.service_ids;

ADMINISTRACIÓN DESDE adminPricing.html
======================================

El paquete Reload ya ha sido integrado en la interfaz de adminPricing.html. Ahora puedes seleccionarlo en la lista de presets ("Reload") y cambiar sus servicios asignados como cualquier otro paquete.
