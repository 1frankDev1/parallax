INSTRUCCIONES PARA ACTIVAR EL PAQUETE "RELOAD"
============================================

1. Ve a la página de pricing.html.
2. En la sección de paquetes (Starter, Premium, Deluxe), verás un botón vacío a la derecha de "Deluxe".
3. Haz clic en ese botón para activar el Modo Reload.
4. Verás una transición de "glitch" y la interfaz cambiará a un tono rojo/oscuro (Modo Especial).
5. En este modo, los servicios se reordenan (Fisical Marketing Kit aparece después de SMM) y los límites de descuento se eliminan (0% a 100%).

SOLUCIÓN AL ERROR DE BASE DE DATOS (package_type)
================================================

Si deseas que el campo 'package_type' sea oficial en tu base de datos y evitar errores futuros al guardar, ejecuta este SQL en Supabase:

ALTER TABLE pricing_packages ADD COLUMN IF NOT EXISTS package_type TEXT;

Nota: El código actual ya ha sido ajustado para guardar el paquete correctamente (dentro del JSON de servicios) incluso si no ejecutas este SQL, para asegurar que no se pierda la información.

SQL PARA ACTUALIZAR PRESETS
===========================

Ejecuta el siguiente SQL para que el preset aparezca en el panel de administración:

INSERT INTO pricing_presets (tier, service_ids)
VALUES ('reload', ARRAY['online_orders', 'local_listing', 'social_media', 'smm', 'physical_marketing'])
ON CONFLICT (tier) DO UPDATE SET service_ids = EXCLUDED.service_ids;
